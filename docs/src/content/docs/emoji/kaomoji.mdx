Kaomoji are Japanese-style faces built from CJK and box-drawing characters, like `(╯°□°）╯︵ ┻━┻`. Western ASCII emoticons like `:-D` and `<3` are the simpler cousin. Both live in one library behind the Kaomoji tab at the end of the emoji panel. The library is yours to change: add faces, give them tags, sort them, star the ones you use, and bring in a library you built in [Emotic](https://f-droid.org/packages/futuristicgoo.emotic/).

## Turning the tab on

<SettingsPath path="Emoji / Emoji panel / Kaomoji tab" />

The tab is off by default. Turn it on and a tab labelled `^_^` appears at the end of the emoji panel's tab strip, after Recent (or Most used) and every Unicode emoji category, so every tab you already know keeps its place.

Kaomoji and emoticons share that one tab. If you would rather keep them apart, turn on <SettingsPath path="Emoji / Emoji panel / Kaomoji / Separate Emoticons tab" /> and a second tab, labelled `:)`, holds the ASCII faces. Each face knows which family it belongs to. A face you add is filed by its characters: printable ASCII alone makes an emoticon, anything else a kaomoji. You can change that in its editor.

All the tab's own settings are on one page:

<SettingsPath path="Emoji / Emoji panel / Kaomoji" />

## Tag tabs

A row of tags runs across the top of the tab. Tap one and the grid shows only the faces under that tag. The row scrolls sideways when it holds more than fits, and keeps the tag you picked in view. It never pages by swiping: a sideways swipe on the panel still moves between emoji categories, as it always did.

The row starts with three tags of its own. Favourites holds the faces you starred and Recent the faces you used, latest first; each appears once it has something in it. All holds every face in your order. Your own tags follow, in the order you gave them. The keyboard ships 312 faces under 18 tags: Happy, Love, Sad, Angry, Table flip, Confused, Surprised, Cool, Cute, Animals, Actions, Sleepy, Greetings, Party, Apologies, Playful, Neutral and Figures. Moods the two families share, such as Happy and Love, are one tag holding both. A face can carry more than one tag and shows under each.

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Open on" /> picks the tag the tab opens on: the last one you used (the default), Recent, Favourites or All.

If you prefer the tab as it used to be, turn off <SettingsPath path="Emoji / Emoji panel / Kaomoji / Tag tabs" />. The tab then shows one long list with a heading for each tag.

## Edit buttons

A narrow column of four buttons sits beside the grid. Search opens the search box. Add opens the editor for a new face, which starts under the tag you have selected. Edit puts the grid in edit mode: tap a face to change it, or hold a face and drag it to a new place, then tap the tick to finish. Tags opens the tag list in place of the grid.

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Edit buttons" /> puts the column on the left (the default) or the right, or turns it off. Under it, one switch for each button keeps only the ones you want. With the column off, the search button sits at the start of the tag row and the other three at its end, so you can still change your faces from the keyboard.

Dragging in edit mode moves a face only among the faces that tag shows. Every face outside that tag keeps its place in All. The Recent tag is in time order, so nothing there can be dragged.

## Holding a face

Hold a face and a bar of actions opens over the bottom of the grid. The star adds the face to Favourites or takes it off. The pencil opens its editor, and the copy button puts it on the clipboard without typing it. The bin asks once more, then removes the face, and the cross closes the bar.

## Adding and changing a face in the keyboard

The editor opens in place of the grid, and the keys come back underneath it so you can type. Type or paste the face into the box at the top. Under it, a row of chips holds every tag: tap a chip to put the face under that tag, or tap it again to take it off. The box at the end of the row types a new tag; press Enter and it joins the face. The first chip switches the face between kaomoji and emoticon.

The tick saves, the cross cancels, and the bin deletes a face that already exists (it asks once more). Enter in the face box also saves.

## The tag list

The Tags button replaces the grid with a list of your tags, each with the number of faces under it. For each tag you can move it up or down the row, hide it from the row with the eye (its faces stay in All), rename it, or delete it. Deleting a tag takes it off its faces and does not delete the faces. Renaming a tag to a name that already exists merges the two. The + at the top adds an empty tag, and the gear opens the library page in the settings app.

## Search

The search button opens a box with the matches above it, and the keys come back underneath. It searches tags and the faces themselves. A tag that matches exactly comes first, then tags that start with what you typed, then tags that contain it, then faces whose characters contain it. Press a match to type it, or press Enter to type the first one.

The emoji panel's own search lists matching faces too, under a Kaomoji heading after the emoji. Turn that off with <SettingsPath path="Emoji / Emoji panel / Kaomoji / Kaomoji in emoji search" />.

## Kaomoji suggestions

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Kaomoji suggestions" />

This is off by default. Turn it on, and when the word you are typing is the name of a tag, the suggestion strip offers up to two faces from that tag in front of the emoji suggestions. Your starred faces come first, then the ones you use most. Add a tag such as `shrug` or `tableflip` to the faces you reach for, and typing that word puts them one tap away. A tag shorter than three letters never triggers this.

A face from the strip goes in the same way an emoji suggestion does: after your word, or in place of it, as <SettingsPath path="Emoji / Suggestions / Press an emoji suggestion" /> decides. Holding it does the other.

## The library in the settings app

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Faces" />

The Faces screen lists every face, filtered by a row of tag chips. Drag a face by its handle to move it, press it to change its text, tags, family and star, and press the bin to delete it. Add a face from the row at the top.

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Tags" />

The Tags screen does the same for tags: drag to reorder the tag row, the eye to hide a tag, the pencil to rename it, the bin to delete it.

Both screens and the keyboard write the same file, so a change in one shows in the other the next time it opens.

## Importing from Emotic and other files

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Import" />

The import reads an Emotic export, a file this keyboard exported, or a plain list.

Emotic 0.1.11 and later export a `.tar.gz` file; older versions export the bare `emoticdb.sqlite` database. The keyboard reads both. It brings in every face with its tags, keeps Emotic's order for the faces and the tags, and drops the repeats Emotic's database can hold.

A plain list has one face on each line. A tab after the face, followed by tags with commas between them, files it under those tags.

Before anything changes, a dialog says how many faces and tags the file holds. **Add** puts the new faces after yours and gives a face you already have any tags it was missing. **Replace all** empties the library first.

Emotic also keeps reaction images, which it calls emotipics. When the export carries some, the keyboard puts them in a new sticker pack named Emotic, with their Emotic tags as the stickers' search words. Images Emotic marked as excluded stay out. See [Stickers](/emoji/stickers/) for using the pack.

Treat an archive from someone else with care. The keyboard reads only the database and the image folder out of it, never writes a file outside its own cache, and refuses an archive past 512 MB or an image past 20 MB.

## Exporting, backing up and resetting

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Export" /> saves your faces, tags, hidden tags and stars to a JSON file. How often you used each face stays behind.

The library also has its own Kaomoji section in [backups](/privacy/backup/), on by default for an export and for automatic backups. Sync leaves it out unless you add it, because every tap on a face changes it.

<SettingsPath path="Emoji / Emoji panel / Kaomoji / Reset the library" /> goes back to the faces the keyboard ships, after one confirmation. It deletes the faces you added, your changes, your stars and your recent faces.

Until you change something or use a face, the library is the built-in set and no file exists. A later version that adds faces to the built-in set shows them to you only while that is still true.

## Inserting long faces safely

A cell shrinks its font size step by step until the whole face fits on one line. It never wraps and never trails off with an ellipsis, since half a kaomoji reads as garbage rather than a smaller version of the same face. The glyph stays invisible for that first layout pass, so you never see it flash past its own edges before settling.

Tapping a cell commits the face as one atomic insert. Any word you were mid-typing is flushed first with autocorrect turned off, and then the face goes in as plain text in a single step. It never passes through autocorrect or auto-capitalization, so `(¬‿¬)` reaches the field exactly as shown.

If <SettingsPath path="Emoji / Emoji panel / Return to the keyboard after you insert" /> is on, tapping a face closes the panel and drops you back on the keys, exactly like a real emoji tap does.

## Details & edge cases

- Faces stay out of emoji history. A face counts for the Kaomoji tab's Recent tag and for the suggestion order, and never for the emoji panel's Recent, Most used or the emoji row.
- The emoji font setting does not apply here. Faces render as plain text with no font override. <SettingsPath path="Emoji / Emoji style / Emoji font" /> only touches genuine Unicode emoji glyphs.
- The built-in faces stick to glyphs Android ships. They use characters covered by Android's bundled fonts (Noto Sans CJK and Noto Sans Symbols), so every one renders out of the box. A face you add can use anything, and may show as boxes on a phone without a font for it.
- In the continuous list, with <SettingsPath path="Emoji / Emoji panel / One long list" /> on, the Kaomoji section starts with its tag row, and that row carries the search, add and tags buttons at its ends. Faces cannot be dragged in that list; use edit mode with the list off, or the Faces screen.
- After a restart, until you unlock the phone once, the tab shows the built-in set, since your library file cannot be read yet.
- The library, the import and the suggestions work the same in every build.
