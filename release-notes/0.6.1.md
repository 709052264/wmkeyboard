Typing is lighter: a typed letter no longer redraws the whole keyboard, and
the suggestion strip and key bubbles reuse their text instead of measuring it
again. A gallery tool, a floating AI button, and a WM Keyboard for the
computer that syncs with the phone over KDE Connect. Under the hood, the
transliteration engines (Avro, Khipro, Bijoy, Hindi, Urdu, the Indic
languages, Persian and Arabic) now run on one Rust engine.

### Faster typing

- A typed letter redraws only the strip and the word it changes, not every
  key. The strip scrolls lazily and asks the app less on each keystroke, and
  the caps mode after a finished word is worked out without asking the app.
- Updates from GitHub install with the app's baseline profile, so the first
  launches after an update are as quick as the ones after it.
- Hindi, Urdu, the Indic languages, Persian, Arabic, Bangla and Assamese load
  a prebuilt phonetic index instead of building one in memory at every start.
  Tamil alone used to take 94 MB ([#716](https://github.com/wasi-master/wmkeyboard/issues/716)).
- Glide reaches long words on big word lists ([#714](https://github.com/wasi-master/wmkeyboard/issues/714)).

### Tools

- **Gallery**: send photos and videos from inside the keyboard, with a quick
  edit and the location data cleared before they go ([#708](https://github.com/wasi-master/wmkeyboard/issues/708)).
- **Floating AI button** and an Ask AI sheet that can read the screen ([#697](https://github.com/wasi-master/wmkeyboard/issues/697)).
  The AI can use the keyboard's own tools, from the calendar and notes to the
  clock and KDE Connect, each one asking first unless you allow it ([#698](https://github.com/wasi-master/wmkeyboard/issues/698)).
  The keyboard's AI chat takes pictures.
- **KDE Connect**: sync with a paired computer, pair by scanning its code,
  send one-time codes to it, pick the computer when sharing to several
  ([#703](https://github.com/wasi-master/wmkeyboard/issues/703)), and clear passwords received from it ([#704](https://github.com/wasi-master/wmkeyboard/issues/704)).
- The toolbox has folders, and a search that opens over the whole keyboard from a button beside the toolbar's back button ([#709](https://github.com/wasi-master/wmkeyboard/issues/709), [#687](https://github.com/wasi-master/wmkeyboard/issues/687)).
- Switch language as a toolbar tool ([#667](https://github.com/wasi-master/wmkeyboard/issues/667)); countdown, planner and date open
  the clock ([#686](https://github.com/wasi-master/wmkeyboard/issues/686)); translate shows three lines of what you type ([#713](https://github.com/wasi-master/wmkeyboard/issues/713)) and
  works with the phone sideways ([#695](https://github.com/wasi-master/wmkeyboard/issues/695)).
- Handwriting models import from files ([#666](https://github.com/wasi-master/wmkeyboard/issues/666)).
- One system spell checker instead of two with the same name: the word lists
  for spelling, Harper for English grammar on top.

### Typing and gestures

- Two-thumb typing: thumbs can take turns, since lifting them all waits a
  moment ([#674](https://github.com/wasi-master/wmkeyboard/issues/674), [#676](https://github.com/wasi-master/wmkeyboard/issues/676)); previews follow the word ([#678](https://github.com/wasi-master/wmkeyboard/issues/678)), an open alternates
  popup is left alone ([#671](https://github.com/wasi-master/wmkeyboard/issues/671)), and the docs say which glide features it turns off ([#675](https://github.com/wasi-master/wmkeyboard/issues/675)).
- Multi-finger swipes work on the keys under a tool's own box ([#712](https://github.com/wasi-master/wmkeyboard/issues/712)).
- Pick mode and F-keys for physical keyboards ([#701](https://github.com/wasi-master/wmkeyboard/issues/701)).
- Elisions and compounds no longer count against a layout in glide ([#707](https://github.com/wasi-master/wmkeyboard/issues/707)).
- Re-casing keeps ß ([#715](https://github.com/wasi-master/wmkeyboard/issues/715)); the touchpad swipe no longer jumps a line ([#682](https://github.com/wasi-master/wmkeyboard/issues/682)).
- A switch takes the accents out of every letter's popup ([#677](https://github.com/wasi-master/wmkeyboard/issues/677)).

### Layouts and languages

- Chinese 联想 stays past the commit and backspace re-picks a conversion
  ([#710](https://github.com/wasi-master/wmkeyboard/issues/710), [#711](https://github.com/wasi-master/wmkeyboard/issues/711)); a conversion pack that loaded empty is read again ([#691](https://github.com/wasi-master/wmkeyboard/issues/691)).
- Korean: double-tap on Danmoeum, and y-vowels from Naratgeul's double key ([#685](https://github.com/wasi-master/wmkeyboard/issues/685)).
- Bangla: ZWNJ and ZWJ on the hasant and full stop holds ([#668](https://github.com/wasi-master/wmkeyboard/issues/668)).
- Bracket keys draw the glyph that right-to-left text shows ([#689](https://github.com/wasi-master/wmkeyboard/issues/689)), and
  symbols on shift appear only while shift is held ([#673](https://github.com/wasi-master/wmkeyboard/issues/673)).
- System default font keeps the phone's own Latin on a script board ([#670](https://github.com/wasi-master/wmkeyboard/issues/670)).

### Fixes

- The keys take the space of a hidden system keyboard bar ([#681](https://github.com/wasi-master/wmkeyboard/issues/681)), and a
  held window height no longer outlives its showing ([#669](https://github.com/wasi-master/wmkeyboard/issues/669)).
- Find stays on its match, Select all stays selected ([#679](https://github.com/wasi-master/wmkeyboard/issues/679)), and the find
  panel keeps room for its toggles ([#688](https://github.com/wasi-master/wmkeyboard/issues/688)).
- Chip undo, even tool heights and the incognito badge on the right field
  ([#665](https://github.com/wasi-master/wmkeyboard/issues/665)).
- Backups leave out only the largest heavy sections ([#692](https://github.com/wasi-master/wmkeyboard/issues/692)).
- About can hide the launcher icon.
